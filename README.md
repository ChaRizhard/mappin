# Mappin

Plan trips day by day on a map: stops, routes, times, budgets and opening hours.
One codebase runs as a website, an installable web app, and iOS/Android apps (via Capacitor).

**New here? Read [SETUP.md](SETUP.md)** for getting it onto your phone, step by step.

## What's in this folder

| Path | What it is |
|---|---|
| `www/` | The app itself: `index.html`, settings (`config.js`), offline support (`sw.js`), icons, install info (`manifest.webmanifest`) |
| `www/vendor/` | Bundled libraries, created by `npm run vendor` (not stored on GitHub; if it's missing, the app loads them online) |
| `assets/` | Source images for the phone apps' icon and splash screen |
| `capacitor.config.json` | Phone app name, ID and launch settings |
| `scripts/` | `copy-vendor.mjs` bundles libraries; `patch-native.mjs` adds the location permission to the phone projects |
| `.github/workflows/` | Free GitHub builds: `website.yml` (GitHub Pages) and `android.yml` (APK) |
| `supabase/schema.sql` | Database setup for the optional cloud sync |
| `signing/` | Test-only Android signing key, so test builds update in place |

The `android/` and `ios/` folders are generated by `npx cap add android|ios` and aren't stored in the repository.

## Data and services

- Trips are stored on the device. Cloud sync (Supabase, free tier) is optional.
- Map images: Google map tiles (unofficial address, fine for private testing only).
- Place search and opening hours: OpenStreetMap (Nominatim, Photon, Overpass) and Wikipedia/Wikidata.
- Walking and driving routes: FOSSGIS OSRM. Public transport opens in Google Maps.

See the roadmap comment at the top of `www/index.html` for moving to the official Google Maps Platform.
